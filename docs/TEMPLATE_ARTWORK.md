# Built-in template artwork

The **Licensed characters** filter in the template library contains published Twemoji artwork by Twitter, Inc. and other contributors. The same pack includes birthday, holiday, botanical, gift, and bow designs under their respective categories.

The thumbnails render the original SVGs and the Rust stitch planner uses those same files. The source is offline after installation. Generated stitch paths are adaptations of the published artwork.

- [Original files at the pinned Twemoji v14.0.2 commit](https://github.com/twitter/twemoji/tree/7a3dad4a4da30497093dab22eafba135f02308e1/assets/svg)
- [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- [Upstream attribution requirements](https://github.com/twitter/twemoji/blob/7a3dad4a4da30497093dab22eafba135f02308e1/README.md#attribution-requirements)

The app displays artwork and license links in template previews. The full upstream graphics license is included beside the vendored sources. If you share an export made from this pack, include the Twemoji credit and license link with the file. For small finished designs, use the stitch preview to check fine details and choose a practical finished width.

# Poolin EOM and other machines sew-out worksheet

Use the machine manual and the dimensions confirmed on the machine to fill in the profile. For an 8 × 9 inch hoop, the nominal dimensions are 203.2 × 228.6 mm. Record the actual **usable embroidery area** from the hoop and machine documentation before configuring it in Stitch Studio.

1. Start with a scrap of the intended fabric. Set up the hoop, stabilizer and needle according to the machine and material guidance.
2. Load a compact test design from approved USB media or the transfer method documented for the machine. Compare the machine display, dimensions and thread sequence with the Stitch Studio worksheet.
3. Run the machine’s documented perimeter or positioning check before sewing. Test first with a known-good design if you need to verify the machine setup.
4. Record the sew-out time and every unexpected stop, jump, trim, break or buildup. Photograph the front and back with a ruler before removing the stabilizer.
5. Compare the outline, interior gaps, thin details, color registration and coverage against the artwork. Change one variable per repeat.

## Export review checks

Open **Sew-out checks** in Export Design Package and save the printable sheet.
For a Poolin profile the section opens automatically and the worksheet includes
the design preview and numbered spool assignments. Check the physical spool on
every block, including blocks that reuse a color. In DST, verify how the machine
handles a color-change record at an intended pause.

Use a short row of puffy lettering to compare adjacent letters for foam exposure,
sealing and even coverage. Use a single appliqué piece to record where the
machine pauses before tack-down and before any manual trimming. In Studio,
**Inspector → Quality** shows suspected coverage gaps and dense needle cells.
Review a repair against the original before exporting the sew-out sample.

## First customer-order rehearsal

Use one small design you can sew twice. A bow beside a short name, with an
open letter such as O or A, makes a practical test for narrow details and
negative space. Save the editable project and export the original and optimized
plans under different names at the same width. Record stitch points, planned
trims, and observed run time on the worksheet. Keep the same fabric, stabilizer,
needle, speed, hoop orientation, and thread assignments for both samples.

Check the openings in the bow and letters, especially near an edited entry or
exit point. In Studio, use **Quality → Coverage gaps** and **Density map** to
investigate visible differences. Save and reopen the optimized project, export
it once more, and compare its dimensions, sewing order, and planned stitch count
with the approved sample. Use the separate foam and appliqué checks above for
orders that use those techniques.
